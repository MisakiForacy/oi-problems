# OI 题目归档

两套题（A～F，共六道），题面与测试数据分开放置，直接下载压缩包即可。

## 下载

| 内容 | 文件 |
| --- | --- |
| 题面（六份 PDF） | `题面_ABCDEF.zip` |
| 测试数据（六套，各 20 组） | `测试数据_ABCDEF.zip` |

也可以在 [Releases](../../releases) 页面下载同样的文件。

## 内容说明

**题面**：CSP 复赛版式，A4，页眉右上是题号字母，页脚标注页码。正文为形式化描述（无故事背景），保留样例、样例解释与数据范围。

**测试数据**：`A/` 到 `F/` 六个目录，每个 20 组 `testN.in` / `testN.out`，另附 `config.yaml` 与样例包 `samples.zip`。

## 使用

```bash
unzip 题面_ABCDEF.zip            # 得到 A.pdf ~ F.pdf
unzip 测试数据_ABCDEF.zip -d data  # 得到 data/A ~ data/F
```

时限 1.0s，内存 256MB，每题 100 分。
